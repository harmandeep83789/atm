# ATM Simulator System

A modular, robust, and secure Automated Teller Machine (ATM) banking simulation system written in Python.

## Roadmap & Architecture
- [x] Initial procedural prototype
- [ ] Core input validation and error boundaries
- [ ] Modular package scaffolding (`atm_app`)
- [ ] Custom banking exception hierarchy
- [ ] Dataclass models for Transactions and Accounts
- [ ] Salted SHA-256 PIN hashing and security policies
- [ ] Multi-account repository and JSON persistence
- [ ] Inter-account transfers and transaction filtering
- [ ] Cash dispenser cassette inventory engine
- [ ] Admin management portal and audit logging
- [ ] Comprehensive test suite and CI automation

## Getting Started
Run the application with Python 3.10+:
```bash
python3 main.py
```
